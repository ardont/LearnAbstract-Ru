# «Твой Путь: Абстрактный Репетитор» (v6.0 Production Ready)

AI-репетитор для школьников, который объясняет сложные школьные темы (математику, физику, химию, биологию, программирование) через увлечения ученика (**спорт, видеоигры, музыку, космос, кино**), проверяет понимание через интерактивные квизы и транслирует успеваемость в дашборд учителя.

---

## 🏛️ Архитектура системы

Проект построен по принципам отказоустойчивой событийно-ориентированной микросервисной архитектуры с полным пакетом **Demo-Resilience (План «Б»)**:

- **Шина событий**: Apache Kafka 3.7.0 в режиме **KRaft** (топики `education.events` и аварийный `education.events.dlq`).
- **Core Service (FastAPI, порт 8000)**:
  - FSM учеников (SQLite/PostgreSQL) с защитой от дублей и накруток (**Quiz Freshness Guard**).
  - Rate Limiting со скользящим окном (10 RPM).
  - **Веб-портал ученика `/student`**: тёмная/светлая тема (с сохранением в `localStorage`), анимированный индикатор набора ответа, таймаут-уведомление 15с, быстрые чипсы популярных тем, бейджи источников RAG и замера задержки (`⚡ 0.2 сек`), адаптивность от 320px.
  - **Управление учебниками**: веб-загрузка PDF с валидацией сканов/размеров, прогресс-баром, действиями переиндексации и удаления.
  - **Кабинет учителя `/teacher`**: автономный встроенный векторный SVG-график активности, рейтинги Top-5 тем и хобби, тепловая карта отстающих тем (Quiz Heatmap) и экспорт отчёта в CSV (UTF-8 BOM).
  - Мониторинг здоровья системы `/health/full` (uptime, метрики RAG/LLM, статус компонентов) и Prometheus-метрики `/metrics`.
- **ML Service (FastAPI, порт 8002)**:
  - **Поисковый RAG-движок**: русскоязычный BM25 Okapi с фильтрацией стоп-слов и стеммингом Snowball.
  - **Формулобезопасный чанкинг**: скользящее окно 1000/200 символов с защитой формул и уравнений от разрыва.
  - **5-уровневый пайплайн генерации**: маршрутизация предмета $\to$ извлечение чанков $\to$ контекстный LLM-промпт $\to$ синтез метафоры $\to$ генерация квиза.
  - **Отказоустойчивый Fallback-каталог**: **100 проверенных экспертных метафор** (20 тем $\times$ 5 хобби) с квизами для мгновенного ответа за 180 мс без интернета.
  - **Output Guardrails**: автопреобразование формул в красивый Unicode (`x²`, `v₀`, `√D`, `π`).
- **Bot Service (порт 8001)**:
  - MAX Бот с полным меню команд: `/start`, `/help`, `/hobby`, `/quiz`, `/profile`, `/reset`.
  - Интерактивные пост-ответные кнопки: `🎯 Пройти тест`, `🔄 Другая метафора`, `📊 Мой прогресс`.
  - Умная классификация намерений (учебный вопрос, отвлечённый смолл-ток, короткий неясный запрос с уточнением).
  - Механизм повторной отправки сообщений с экспоненциальной задержкой (Retry with exponential backoff).
  - Watchdog-таймер (45 сек) с отменой при получении ответа.
  - Согласие по 152-ФЗ (кнопки согласия, гостевой режим, информация о проекте).

## 🐧 Быстрый старт (Quickstart)

### 1. Подготовка окружения
```bash
# Клонирование и переход в репозиторий
git clone <URL_РЕПОЗИТОРИЯ> && cd repo
mkdir -p data/textbooks data/vector_db backups
```

### 2. Конфигурация (.env)
```bash
cp .env.example .env
# Заполните токен бота MAX_BOT_TOKEN и пароль учителя TEACHER_PASSWORD в .env
```

### 3. Запуск инфраструктуры
```bash
docker compose up -d kafka kafka-init postgres redis
```

### 4. Подготовка базы знаний учебников (RAG)
```bash
# Генерация тестового учебника и формулобезопасная индексация
python scripts/create_sample_pdf.py
python scripts/ingest_textbook.py --subject algebra --pdf tests/fixtures/sample_textbook.pdf
```

### 5. Инициализация БД и демо-данных
```bash
python scripts/seed_demo_data.py
```

### 6. Экспресс-проверка готовности перед демонстрацией
```bash
python scripts/pre_demo_check.py
# Критерий готовности: 🚀 ALL SYSTEMS GO! YOU ARE READY TO DEMO!
```

### 7. Запуск всех сервисов локально
```bash
python scripts/run_all_local.py
```

## 🔧 Диагностика и решение проблем (Troubleshooting)

### 1. Ошибка: Kafka не стартует или контейнер в статусе Restarting
- **Решение**:
  ```bash
  docker compose down -v && docker compose up -d kafka kafka-init
  ```

### 2. Ошибка: Порт занят (8000, 8001, 8002)
- **Решение в Windows PowerShell**:
  ```powershell
  Get-NetTCPConnection -LocalPort 8000,8001,8002 | Select-Object OwningProcess
  Stop-Process -Id <PID> -Force
  ```

### 3. Ошибка: Переменные из `.env` не подхватываются
- **Решение**: Убедитесь, что `.env` сохранён в кодировке `UTF-8 без BOM` и запускается из корневой папки `repo/`.
