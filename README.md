# «Твой Путь: Абстрактный Репетитор» (Firstapp) · v6.0 Production Ready

> **AI-репетитор для школьников 5–7 классов**, который объясняет сложные школьные понятия (математику, физику, биологию, информатику) через увлекательные для конкретного ребёнка абстракции и хобби (**спорт, видеоигры, музыку, космос, кино**), опираясь на школьные учебники через RAG, моментально проверяет усвоение через интерактивные квизы и транслирует успеваемость в кабинет учителя.

## ⚡ Быстрый старт (Quickstart за 3 команды)

### Предварительные требования
* **Docker & Docker Compose** (для запуска Kafka, Postgres, Redis)
* **Python 3.11+**
* Свободная память: от 4 ГБ RAM

### Запуск проекта

```bash
# 1. Клонирование репозитория
git clone https://github.com/officialramistt-source/hackathonMax.git
cd hackathonMax

# 2. Настройка переменных окружения
cp .env.example .env
# (При необходимости укажите MAX_BOT_TOKEN и TEACHER_PASSWORD в .env)

# 3. Единый запуск всей системы (Linux / macOS)
chmod +x scripts/start.sh scripts/stop.sh
./scripts/start.sh
```

> **Для Windows**: просто запустите `scripts\start.bat` двойным кликом или в PowerShell!

## 🧪 Сценарий живой демонстрации (Шаг за шагом)

### Сценарий 1: Проверка через Web-портал ученика (`/student`)
1. Откройте `http://localhost:8000/student`.
2. Выберите класс (**5–7 класс**) и хобби: например, **«⚽ Футбол»**.
3. Задайте вопрос: **«Объясни квадратные уравнения»** (или нажмите на быстрый чипс).
4. Проверьте:
   - Появляется анимированный индикатор набора.
   - Ответ содержит яркую футбольную метафору (парабола полёта мяча, дискриминант как проверка пересечения ворот, корни уравнения).
   - Формулы отображаются в Unicode (`x²`, `√D`, `ax² + bx + c = 0`).
   - Зелёный бейдж `📚 RAG: N чанков` со ссылкой на проиндексированный учебник алгебры.
   - Раскройте цитаты RAG: точные выдержки с номерами страниц из учебника.
   - Пройдите микро-тест под ответом: система мгновенно подсветит верный ответ.
5. Во вкладке **«📚 Загрузка в RAG»** убедитесь в наличии активных проиндексированных учебников.

### Сценарий 2: Проверка через чат-бота в MAX (`@t569_hakaton_max_bot`)
1. Откройте чат-бота [https://max.ru/t569_hakaton_max_bot](https://max.ru/t569_hakaton_max_bot).
2. Отправьте `/start`.
3. Подтвердите согласие по 152-ФЗ нажатием `[✅ Согласен]`.
4. Выберите хобби: `[⚽ Футбол]` или `[🎮 Видеоигры]`.
5. Отправьте запрос: `Объясни квадратные уравнения`.
6. Нажмите `🎯 Пройти тест` и выберите вариант ответа.
7. Нажмите повторно на тот же тест — убедитесь, что сработал **Quiz Freshness Guard** (защита от повторного прохождения).
8. Отправьте команду `/profile` для просмотра успеваемости и набранных очков XP.

### Сценарий 3: Кабинет учителя (`/teacher`)
1. Перейдите на `http://localhost:8000/teacher` и авторизуйтесь (`teacher` / `change_me_in_production`).
2. Ознакомьтесь с векторным графиком активности за неделю.
3. Проанализируйте **Тепловую карту успеваемости (Quiz Heatmap)** для выявления тем, вызывающих трудности у учеников.
4. Нажмите кнопку **«Скачать CSV»** — скачается валидный файл отчёта в кодировке UTF-8 с BOM, корректно открывающийся в Microsoft Excel.
