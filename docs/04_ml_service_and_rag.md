## 1. Роль и архитектура ML Service

**ML Service** (порт 8002, `services/ml_service/main.py`) — интеллектуальное ядро платформы, отвечающее за:
* Поиск релевантных фрагментов школьных учебников с помощью собственного поискового движка **BM25 Okapi**.
* Дидактическую оркестрацию промптов к большим языковым моделям (**DeepSeek / Ollama / OpenAI**).
* Формулобезопасный чанкинг учебных пособий с сохранением целостности математических выражений.
* Конвертацию формул из сырого LaTeX в читаемый **Unicode** для мессенджера MAX.
* Двухуровневую фильтрацию безопасности (**Input & Output Guardrails**).
* Мгновенный 5-уровневый **Fallback-конвейер** с каталогом из **100 выверенных метафор** (гарантированный ответ за 180 мс при сбое внешних нейросетей).

```
                            [ Входящее событие ]
                    (explanation.requested из Kafka/REST)
                                     │
                                     ▼
                      ┌──────────────────────────────┐
                      │    Input Guardrails Check    │
                      │  (Prompt Injection & Safety) │
                      └──────────────┬───────────────┘
                                     │ Запрос безопасен
                                     ▼
                      ┌──────────────────────────────┐
                      │    BM25 Okapi RAG Engine     │
                      │  (Поиск 3 чанков в учебнике) │
                      └──────────────┬───────────────┘
                                     │ Найдены фрагменты теории
                                     ▼
                      ┌──────────────────────────────┐
                      │   LLM Client Orchestration   │
                      │  (DeepSeek-V3 / Ollama API)  │
                      └──────────────┬───────────────┘
                                     │
                     ┌───────────────┴───────────────┐
                     │ Успех                         │ Ошибка / Таймаут
                     ▼                               ▼
       ┌───────────────────────────┐   ┌───────────────────────────┐
       │     Output Guardrails     │   │   5-Tier Fallback Catalog │
       │  (Токсичность, PII, длина)│   │  (100 метафор / 180 мс)   │
       └─────────────┬─────────────┘   └─────────────┬─────────────┘
                     │ Валидно                       │
                     └───────────────┬───────────────┘
                                     ▼
                      ┌──────────────────────────────┐
                      │   LaTeX -> Unicode Engine    │
                      │   (x^2 -> x², \sqrt{} -> √)  │
                      └──────────────┬───────────────┘
                                     ▼
                      [ Событие: explanation.ready ]
```

## 2. Формулобезопасный чанкинг учебников (`scripts/ingest_textbook.py`)

Стандартные библиотеки чанкинга (например, `RecursiveCharacterTextSplitter` из LangChain) разрезают текст строго по счетчику символов или токенов.  
**Критическая проблема**: В точных науках (алгебра, физика, геометрия) механический разрез неизбежно разрушает математические формулы. Если выражение `$$x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$` разрезать посередине, нейросеть получит поврежденный синтаксис и выдаст галлюцинацию.

### Алгоритм `split_text_into_chunks()`:
* **Базовый размер чанка**: 1000 символов.
* **Перекрытие (Overlap)**: 200 символов (для сохранения контекста между соседними фрагментами).
* **Поиск запретных зон формул (`get_formula_spans`)**:
  ```python
  def get_formula_spans(text: str) -> List[Tuple[int, int]]:
      spans = []
      # Блочные формулы $$ ... $$
      for m in re.finditer(r'\$\$[^\$]+\$\$', text, re.DOTALL):
          spans.append((m.start(), m.end()))
      # Строчные формулы $ ... $
      for m in re.finditer(r'\$[^\$]+\$', text):
          spans.append((m.start(), m.end()))
      # Окружения LaTeX \begin{...} ... \end{...}
      for m in re.finditer(r'\\begin\{[a-zA-Z0-9*]+\}.*?\\end\{[a-zA-Z0-9*]+\}', text, re.DOTALL):
          spans.append((m.start(), m.end()))
      return sorted(spans, key=lambda x: x[0])
  ```
* **Иерархический выбор границы разрыва**:
  1. Двойной перевод строки (`\n\n`, граница логического абзаца).
  2. Одинарный перевод строки (`\n`).
  3. Граница предложения (`.`, `!`, `?`).
  4. Граница слова (пробел).
* Если точка предполагаемого разделения попадает внутрь формулы, граница смещается за пределы формульного диапазона (`is_inside_formula(pos) == False`). Формула всегда остается неделимой.

## 3. Поисковый движок BM25 Okapi со стеммингом (`services/ml_service/rag_engine.py`)

В системе реализован автономный алгоритм **BM25 Okapi** без внешних тяжелых зависимостей (ChromaDB, FAISS), что гарантирует холодный старт за 0.5 секунды и надежную работу в легковесных Docker-контейнерах.

### 1. Предобработка и токенизация:
* **Фильтрация стоп-слов**: словарь `RUSSIAN_STOP_WORDS` (40+ союзов, предлогов и местоимений).
* **Морфологический анализ**:
  * Если в окружении установлен `pymorphy3` — применяется лемматизация в начальную словарную форму.
  * Если `pymorphy3` отсутствует — включается встроенный русский стеммер `_stem_simple(token)`, отсекающий падежные и глагольные флексии (`-ами`, `-ов`, `-ие`, `-ить`, `-ут` и др.).

### 2. Математика алгоритма BM25 Okapi:
Для каждого термина $q \in Q$ (где $Q$ — запрос ученика) и документа $D$:

$$\text{IDF}(q) = \ln \left( 1 + \frac{N - n(q) + 0.5}{n(q) + 0.5} \right)$$

Где:
* $N$ — общее количество чанков в индексе учебника.
* $n(q)$ — Document Frequency (число чанков, содержащих термин $q$).
* Слагаемое $1 + ...$ защищает формулу Lucene от отрицательных значений при $n(q) > \frac{N}{2}$.

Итоговый скор релевантности чанка:

$$\text{Score}(D, Q) = \sum_{q \in Q} \text{IDF}(q) \cdot \frac{f(q, D) \cdot (k_1 + 1)}{f(q, D) + k_1 \cdot \left(1 - b + b \cdot \frac{|D|}{\text{avgdl}}\right)}$$

* **Гиперпараметры**:
  * $k_1 = 1.5$ (насыщение частоты термина).
  * $b = 0.75$ (штраф за длину документа относительно средней длины $\text{avgdl}$).
* **Ранжирование**: Модуль возвращает топ-3 чанка с наивысшим скором для подмешивания в промпт.

## 4. Дидактический промпт и оркестрация LLM (`llm_client.py`)

Промпт построен по 3-шаговой педагогической схеме, предписанной методикой проекта:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        СТРУКТУРА СИСТЕМНОГО ПРОМПТА                    │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Роль: Чуткий школьный репетитор по предмету {subject} для {grade} кл│
│ 2. Интерес ученика: {interest} (Футбол, Видеоигры, Музыка и др.)       │
│ 3. Теоретическая база (RAG Context): {top_3_chunks_from_textbook}      │
├────────────────────────────────────────────────────────────────────────┤
│ 4. Жёсткий формат ответа:                                              │
│    • Шаг 1: Метафора из мира хобби (2-3 ярких предложения)             │
│    • Шаг 2: Формула (строгая запись закона из учебника)                │
│    • Шаг 3: Практический вывод (связка аналогии с формулой)            │
│    • Микро-квиз: Вопрос, 4 варианта ответа, правильный индекс, разбор  │
└────────────────────────────────────────────────────────────────────────┘
```

* **Поддерживаемые LLM**: DeepSeek-V3, DeepSeek-R1 (Distill), Llama-3 (Ollama), локальные квантованные модели GGUF.
* **Таймаут**: 8.0 секунд (при превышении — автоматический переход на Fallback).
* **Валидация JSON**: Извлечение структуры квиза через Regex с устойчивостью к Markdown-тегам ` ```json ... ``` `.

## 5. Система безопасности Guardrails (`services/ml_service/guardrails.py`)

Для защиты несовершеннолетних пользователей и стабильности сервиса работает двухуровневый шлюз безопасности:

### 1. Input Guardrails (`check_guardrails`):
* **Защита от Prompt Injection**: блокировка попыток взлома системного контекста (`ignore previous instructions`, `you are now in dan mode`, `jailbreak`, `забудь предыдущие инструкции`).
* **Фильтрация запретных тем**: детекция запросов об оружии, взрывчатых веществах, наркотиках, суициде и нецензурной брани.

### 2. Output Guardrails (`OutputGuardrails`):
Фильтрует ответ нейросети перед отправкой ученику:
* **Запрещенные паттерны опасных практик**: примеры с поражением электрическим током (`удар током`), взрывами, колюще-режущими предметами.
* **Защита от утечек персональных данных (PII)**: телефонные номера (`+7...`), адреса электронной почты.
* **Ограничение длины**: максимум 4000 символов (лимит сообщения мессенджера MAX).

## 6. Конвертер формул: LaTeX → Unicode (`text_formatter.py`)

Мессенджер MAX (как и большинство мобильных чатов) не имеет встроенного MathJax/KaTeX-рендерера. Если отправить школьнику сырой LaTeX:
```latex
y = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
```
текст превращается в нечитаемую абракадабру.

В `shared/utils/text_formatter.py` реализован парсер, трансформирующий математические символы в читаемый Unicode:

| LaTeX исходник | Преобразование в Unicode | Результат для школьника |
| :--- | :--- | :--- |
| `x^2 + y^2 = r^2` | Таблица `SUPERSCRIPTS` | `x² + y² = r²` |
| `x_1, x_2` | Таблица `SUBSCRIPTS` | `x₁, x₂` |
| `\frac{U}{R}` | Регэкс `\frac{A}{B} \to (A / B)` | `(U / R)` |
| `\sqrt{D}` | `\sqrt{A} \to √(A)` | `√(D)` |
| `\Delta, \alpha, \omega` | Таблица `GREEK_SYMBOLS` | `Δ, α, ω` |
| `\times, \pm, \leq, \approx` | Таблица `MATH_OPERATORS` | `×, ±, ≤, ≈` |

## 7. 5-уровневый Fallback-конвейер («План Б»)

Если внешняя нейросеть недоступна, зависла или выдала ошибку валидации, ML Service активирует каскадный Fallback:

```
[ Запрос ученика ]
       │
       ├─► 1. Точное совпадение (Exact Match в metaphor_engine.py)
       │      • Быстрый словарь горячих тем хакатона
       │
       ├─► 2. Каталог 100 метафор (fallback_catalog.py)
       │      • 20 школьных тем × 5 увлечений (Футбол, Баскетбол, Видеоигры, Музыка, Кино)
       │      • Задержка: 180 мс! Нулевой расход токенов.
       │
       ├─► 3. Предметный генератор (Subject-level Fallback)
       │      • Шаблоны по разделам: Алгебра, Физика, Информатика, Биология
       │
       ├─► 4. Универсальный репетитор (General Fallback)
       │      • Дидактическая подсказка с приглашением уточнить формулу
       │
       └─► 5. Dead Letter Queue (DLQ в Kafka)
              • Публикация в education.events.dlq для анализа инженерами
```

Каталог `fallback_catalog.py` весит 170 КБ и гарантирует, что даже при полном отключении интернета и падении серверов LLM **презентация и демонстрация для жюри отработают безупречно**.
