# RAG (Retrieval-Augmented Generation) по школьным учебникам (v6.0)

Модуль RAG усиливает генерацию аналогий точными цитатами, теоремами и формулами из официальных школьных учебников, сохраняя при этом живую и увлекательную подачу через метафору ученика.

## ✂️ Формулобезопасный чанкинг (Formula-Safe Chunking)

В скрипте `scripts/ingest_textbook.py` и `services/ml_service/rag_engine.py` реализован интеллектуальный алгоритм сегментации:

1. **Размер окна**: скользящее окно 1000 символов с перекрытием (overlap) 200 символов.
2. **Защита формул и уравнений**:
   - Регулярные выражения защищают математические и физические формулы (LaTeX `$...$`, `$$...$$`, уравнения `ax² + bx + c = 0`, законы Ома `I = U / R`, кинематику `v = v₀ + at` и др.).
   - Разрез чанка никогда не производится внутри блока формулы.
3. **Естественные границы**:
   - Точки разбиения подбираются по границам абзацев (`\n\n`), предложений (`. `, `! `, `? `) или пробелов.
   - Запрещено обрывать слова на полуслове.
4. **Метаданные чанка**:
   - Каждый чанк содержит `chunk_id`, `text`, `subject`, `source_file`, `page_number` и временную метку индексации.

## 🔍 Поисковый движок BM25 Okapi для русского языка

Вместо примитивного поиска по подстрокам используется полнотекстовый лексический ранжировщик **BM25 Okapi**, оптимизированный для русского языка:

1. **Русская токенизация и очистка**:
   - Приведение к нижнему регистру, удаление пунктуации.
   - Фильтрация стоп-слов русского языка (союзы, предлоги, частицы: «и», «в», «на», «с», «по», «как», «что» и т.д.).
2. **Стемминг**:
   - Использование стеммера Snowball (`nltk.stem.snowball.RussianStemmer`) с автоматическим откатом на эвристический префиксный стеммер без внешних зависимостей.
   - Запросы вроде «квадратных уравнений» корректно находят чанки со словами «квадратное уравнение», «уравнением».
3. **Ранжирование BM25**:
   - Параметры: $k_1 = 1.5$, $b = 0.75$.
   - Учёт Inverse Document Frequency (IDF) и относительной длины документа.
   - Порог отсечения низкорелевантного шума (`min_score = 0.5`).

## 🛡️ 5-уровневый пайплайн генерации и Fallback

1. **Маршрутизация**: Core Service классифицирует предмет (`algebra`, `physics`, `cs`, `biology`, `chemistry`).
2. **Поиск RAG**: Извлечение топ-3 чанков учебника с указанием страниц.
3. **Промптинг LLM**: В системный промпт модели внедряется цитируемый контекст учебника:
   ```
   КОНТЕКСТ ИЗ ШКОЛЬНОГО УЧЕБНИКА (Используй термины и формулы отсюда):
   [Страница 42]: Квадратным уравнением называется уравнение вида ax² + bx + c = 0...
   ```
4. **Гарантированный Fallback (100 метафор)**:
   - Если RAG не нашёл подходящий чанк или LLM недоступна (таймаут 15с / режим офлайн), срабатывает встроенный вычитанный экспертный каталог: **20 тем × 5 хобби = 100 готовых метафор с квизами**.
5. **Преобразование формул**: Все формулы на выходе переводятся в читаемый Unicode (`x²`, `v₀`, `√D`, `π`, `→`), исключая «сырой» непригодный для мессенджеров LaTeX.

## 📊 Мониторинг и метрики RAG

Метрики RAG собираются в `services/ml_service/metrics.py` и отображаются в `/health/full`:
- `rag_queries_total`: общее число поисковых запросов в базу учебников.
- `rag_hits_total`: количество успешных нахождений контекста.
- `rag_hit_rate_pct`: процент попаданий ($\frac{\text{hits}}{\text{queries}} \times 100\%$).
- Статус наличия индексов по каждому предмету.
