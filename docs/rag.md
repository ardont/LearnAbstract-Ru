# RAG (Retrieval-Augmented Generation) по школьным учебникам

Модуль RAG усиливает генерацию аналогий точными цитатами, теоремами и формулами из официальных школьных учебников, сохраняя при этом живую и увлекательную подачу через метафору ученика.

---

## 📂 Структура каталогов

```
repo/
├── data/
│   ├── textbooks/          # Исходные PDF-учебники (алгебра, физика, химия, биология)
│   │   └── algebra_7.pdf
│   └── vector_db/          # Persistent индекс с чанками и лексическими весами
│       ├── algebra/
│       │   └── index.json  # Проиндексированные чанки по алгебре
│       └── physics/
│           └── index.json
```

## 🚀 Индексация учебника

Для загрузки нового учебника запустите скрипт:
```bash
python scripts/ingest_textbook.py --subject algebra --pdf data/textbooks/algebra_7.pdf
```

### Встроенные валидации:
1. **Проверка файла**: выбрасывает `FileNotFoundError`, если путь не существует.
2. **Проверка шифрования**: выбрасывает `ValueError`, если PDF защищён паролем.
3. **Детектор сканов**: проверяет объём извлечённого текста. Если длина < 100 символов, информирует о необходимости предварительного OCR.
4. **Умный чанкинг**: деление по 1000 символов с перекрытием 200 символов по границам предложений и абзацев.

---

## ⚡ Принцип работы в пайплайне

1. **Определение предмета (`subject`)**: Core Service автоматически определяет предмет запроса (`algebra`, `physics`, `cs`, `biology`) по ключевым словам темы.
2. **Поиск релевантных фрагментов**: `rag_engine.retrieve(query, subject, k=3)` находит топ-3 наиболее подходящих фрагментов по TF-IDF и Term Overlap.
3. **Промптинг LLM**: найденные фрагменты передаются модели как строгий академический контекст:
   ```
   Используй следующие строгие академические определения и факты из школьного учебника:
   [Фрагмент 1]
   [Фрагмент 2]
   ```
4. **Graceful Degradation**: если учебник по предмету ещё не загружен или поиск не вернул результатов, генератор плавно продолжает работу без контекста, не прерывая диалог.
5. **Взаимодействие с Demo-Resilience**: в режиме `DEMO_MODE=true` модуль RAG минуется для обеспечения мгновенного ответа за 180 мс из локального вычитанного каталога.

## 📊 Метрики RAG

Метрики регистрируются через Prometheus в `services/ml_service/metrics.py` и доступны в сводном дашборде `GET /health/full`:
- `rag_queries_total`: общее число поисковых запросов в базу учебников.
- `rag_hits_total`: количество запросов, в которых был найден релевантный контекст.
- `rag_hit_rate_pct`: процент успешных попаданий ($\frac{\text{hits}}{\text{queries}} \times 100\%$).
