# 📚 Инженерная книга проекта «Твой Путь: Абстрактный Репетитор»
### Полное техническое руководство для изучения с нуля и защиты проекта

Добро пожаловать в структурированную базу знаний проекта **«Твой Путь: Абстрактный Репетитор» (Firstapp · v6.0)**.  
Этот интерактивный справочник организован как модульная книга с перекрестными гиперссылками. Любой инженер, методист или член экзаменационной комиссии может с нуля изучить устройство всей системы — от педагогической концепции до ассемблера очередей Kafka и схем валидации Pydantic.

---

## 🧭 Интерактивное оглавление книги

| Глава | Название документа | Ключевые темы и модули |
| :---: | :--- | :--- |
| **01** | [💡 Идея, проблематика и педагогика абстракций](./01_idea_and_pedagogy.md) | EdTech-кризис в 5–7 классах, теория когнитивной нагрузки Свеллера, модель двойного кодирования Пайвио, 3-шаговый дидактический цикл. |
| **02** | [🏛️ Архитектура системы и сквозные потоки данных](./02_architecture_overview.md) | High-Level Design, Event-Driven архитектура, C4-контейнеры, сквозной путь запроса («Life of a Request»), Correlation ID. |
| **03** | [🧠 Core Service — Координатор, FSM и BFF](./03_core_service.md) | Конечный автомат (`fsm.py`), комплаенс 152-ФЗ, Rate Limiter на 10 RPM (`rate_limiter.py`), дашборд учителя (`/teacher`), экспорт CSV с BOM. |
| **04** | [🔬 ML Service — RAG, Чанкинг и Генерация метафор](./04_ml_service_and_rag.md) | Формулобезопасный чанкинг (1000/200), BM25 Okapi со стеммингом (`rag_engine.py`), Guardrails и Unicode-формулы, 5-уровневый Fallback (100 метафор). |
| **05** | [🤖 Bot Service — Шлюз мессенджера MAX](./05_bot_service_and_max.md) | Клиент umaxbot, классификатор интентов, идемпотентность и дедупликация (`idempotency.py`), Watchdog-таймеры (`watchdog.py`), инлайн-клавиатуры. |
| **06** | [⚡ Шина сообщений Apache Kafka (KRaft)](./06_event_bus_kafka.md) | Режим KRaft без ZooKeeper, топики `education.events` и `education.events.dlq`, контракт `EventEnvelope`, ручной коммит офсетов (At-Least-Once), Dead Letter Queue. |
| **07** | [💾 Хранилища данных: PostgreSQL и Redis](./07_data_storage_pg_redis.md) | Реляционная БД SQLAlchemy+asyncpg (`models.py`, таблицы users, quiz, logs), fallback на SQLite, Redis Sorted Sets для sliding window и атомарный SET NX. |
| **08** | [📑 Спецификация API и схемы данных (Swagger/DTO)](./08_api_and_swagger.md) | Разбор всех 5 групп эндпоинтов, полный анализ всех Pydantic DTO (Schemas), HTTP-статусы, валидация 422 Unprocessable Entity. |
| **09** | [📈 Масштабирование и эксплуатация в Production](./09_scalability_and_production.md) | Анализ текущего масштаба vs 100 000+ учеников, партиционирование Kafka по hash(user_id), семантическое кэширование, кластер vLLM, Qdrant Vector DB. |
| **10** | [🛡️ Руководство по защите и ответы на каверзные вопросы](./10_defense_guide_and_faq.md) | Тайминг выступления на 3-5 минут, сценарий демонстрации экранов, топ-15 коварных вопросов жюри и готовые инженерные ответы. |
| **REF**| [🗺️ Справочник кодовой базы: директории, модули и функции](./codebase_reference.md) | Полный анатомический разбор структуры каждого каталога, каждого сервиса, класса и каждой функции с сигнатурами и связями. |
